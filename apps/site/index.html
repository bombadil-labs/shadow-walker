Start with your own machine

One server. One saved exploration.

Use Node 24.11 or later in the 24.x line. In WSL, work from the Linux filesystem and keep the database directory between restarts.

git clone https://github.com/bombadil-labs/shadow-walker.git
cd shadow-walker
npm ci
npm run check
node dist/apps/server/src/index.js --http

Open http://localhost:3001/ on that machine. The MCP endpoint is http://127.0.0.1:3001/mcp. Create an exploration in chat, then use “Refresh from server” in the workbench.

Local mode is single-user and has no account login. Do not expose this server through a public forwarding URL. Publishing this landing page does not publish the MCP or your local database.

ChatGPT · private development

  1. Run the server locally and connect it through OpenAI’s Secure MCP Tunnel.
  2. Create a developer-mode app/connection, select that tunnel, and use no additional server OAuth for this private, access-controlled local setup.
  3. Enable Shadow Walker in a chat. Ask it to take one step and stop for your review.

Claude · local or remote

For a local Claude Desktop MCP, build the repository and configure the host to launch the server directly from that repository’s working directory:

node dist/apps/server/src/index.js

Claude’s remote custom connector connects from Anthropic’s cloud, not your computer. A future hosted setup will use Customize → Connectors → Add custom connector, your authenticated public MCP URL, and OAuth. Do not use our loopback URL as a remote connector.
